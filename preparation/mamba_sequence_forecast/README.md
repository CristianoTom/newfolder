# 用 Mamba 做时间序列预测

假设你每隔一小时记录一个温度。你手头已经有最近 32 小时的数据，希望预测接下来 8 小时。这个例子做的就是这件事，只是用程序生成的带噪声波形代替温度记录。模型是教学版 Mamba-1，可以在 CPU 上训练。

## 运行

在 `newfolder` 根目录打开终端，执行下面两行。已经安装 PyTorch 和 Matplotlib 时，直接执行第二行。

```powershell
python -m pip install torch matplotlib
python preparation/mamba_sequence_forecast/train.py
```

第一次想快速看完整流程，可以先跑一轮。想看训练曲线，直接用上面的默认命令，它会跑 15 轮。

```powershell
python preparation/mamba_sequence_forecast/train.py --epochs 1
```

## 第一次读代码的顺序

从 [train.py](train.py) 底部的 `main()` 开始。里面按六步标了注释。读到一个不熟悉的函数时，可以跳到它的定义，只看它接收什么、返回什么，再回到 `main()` 接着读。[model.py](model.py) 建议从 `MambaForecaster.forward()` 读起，等看懂输入和输出，再看 `MambaMixer.selective_scan()`。[plots.py](plots.py) 负责读 JSON 和画图，可以放到最后。

### 1. 滑动窗口怎样从一条长序列造出样本

先用小数字手算。假设历史长度为 3、预测步数为 2，原始序列是 `[10, 12, 11, 13, 15, 14]`。

| 第一个要预测的索引 | 历史，模型看到的输入 | 目标，训练时用来算误差 |
| --- | --- | --- |
| 3 | `[10, 12, 11]` | `[13, 15]` |
| 4 | `[12, 11, 13]` | `[15, 14]` |

代码里的 `forecast_start` 就是表格第一列。索引为 3 时，`values[0:3]` 取到索引 0、1、2，`values[3:5]` 取到索引 3、4。训练窗口每次移动 2 个点来减少重复计算，验证和测试窗口每次移动 1 个点。

划分数据时，训练、验证、测试各用自己那段的**目标**。例如默认测试从索引 576 开始，第一个测试窗口的历史是索引 544 到 575，目标是 576 到 583。计算均值和标准差只用训练段，其余各段沿用这两个数。模型输出也用同样的统计量恢复成原始单位。

### 2. 方括号里的形状是什么意思

| 位置 | 默认形状 | 各维度的意思 |
| --- | --- | --- |
| 一个历史窗口 | `[32, 1]` | 32 个时间点，每点 1 个数 |
| DataLoader 拼出的一批输入 | `[32, 32, 1]` | 32 个窗口，每个窗口 32 个点，每点 1 个数 |
| 经过输入映射 | `[32, 32, 24]` | 窗口数和时间点数保持相同，每点变为 24 个模型特征 |
| 取最后一个历史位置 | `[32, 24]` | 每个窗口留下一组 24 个特征 |
| 最终输出和训练目标 | `[32, 8]` | 每个窗口给出 8 个未来值 |

两个 32 含义不同。第一个是批量大小，最后一批可能不足 32。第二个是历史长度，可通过 `--history` 修改。第一次运行时，终端里的 `One window` 会打印单个样本的实际形状。

### 3. Mamba 怎样一步一步读历史

1. 因果卷积提取近几个时间点的变化。默认卷积核宽度是 4，因此读到第 7 个点时，只会使用第 4 到第 7 个点。开头缺少的历史用 0 填充。
2. 选择性扫描按时间从左到右更新内部状态。代码里的 `retained_state` 是留下的旧状态，`new_information` 是当前输入写进去的内容，两者相加得到新状态。举个只看一个状态的例子，旧值为 2，保留比例为 0.75，新写入 0.5，更新后就是 `2 × 0.75 + 0.5 = 2`。实际模型会同时更新很多状态。
3. “选择性”指的是步长、写入权重和读取权重都由当前特征计算，因此每个时间点可以保留和读出不同的信息。扫描结束后，预测头用最后一个历史位置的特征直接输出未来 8 个点。

### 4. 训练误差和测试误差怎么读

每轮训练中，`train_one_epoch()` 依次取一批窗口、预测、计算误差、反向传播、更新参数。每轮结束，用验证 MAE 决定是否保留该轮参数。最终用保留下来的参数在测试段算 MAE 和 RMSE。MAE 是预测与真值相差多少的平均值，RMSE 会更强调较大的误差。两者都使用原始数据的单位。

终端还会给出 `persistence MAE`。这是一个简单对照：如果最后观测到的是 14，就把未来每一步都预测成 14。末尾的 `+1`、`+2` 等是从最后一个已知观测之后开始计数。

如需使用自己的数据，可以把 `main()` 里的 `observed = make_series(...)` 改成 `observed = torch.tensor(your_values, dtype=torch.float32)`。`your_values` 是按时间从早到晚排列、等间隔采样的一维数值列表。可以先用 `--history 12 --horizon 3` 试跑，确认窗口和预测点的位置符合预期。

选择性状态空间模型和状态递推公式参考 [Mamba 论文](https://arxiv.org/abs/2312.00752) 与[官方选择性扫描实现](https://github.com/state-spaces/mamba/blob/main/mamba_ssm/ops/selective_scan_interface.py)。
